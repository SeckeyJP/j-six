# 判定シナリオ（合成期待値）

2026-09-26。実装・実行結果ではない。企業・実データ・実承認を使わず、[実行契約R1〜R8](execution-contract.md)を後続の合成試験の期待値として具体化する。

既定前提S: 仮想Program P、Task T、成果物hash A、IF/DB版V、固定run方針P1、環境E、信頼/権限台帳Kが一致。必須検査はすべて実行済みpassed、必要なPhase承認が有効、時刻/失効確認可、Git保存可、実行/レビュー枠あり。表の条件だけを変更する。「許可」は対象操作1件の許可であり、品質や全工程の認証ではない。

C03/C04/C08等の非免除条件がC06と同時に起きたら保留を優先する。例外は特定した条件のみを覆い、他の未達を覆わない。C10/C17等の複数条件は、実装試験では各条件を別ケースに分解する。記録だけから署名・OS隔離・実際の外部作用阻止を証明しない。

C16の完了照合後でも、失効・対象変更・旧世代なら結果取込みは保留する。復旧の成功と現在の受入可否を分離する。実行側に照合/冪等性/世代確認がない経路ではC17の保証をせず、自動再送を対象外として保留する。
