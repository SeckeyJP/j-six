### 3.3 受入条件と Property（PROP）

各要件の受入条件を、**個別の例**と、入力空間全体で成り立つべき**性質（Property）**の両方で書く。
例だけを検証面にすると、その例だけを通す実装が成立してしまうためである（J-SIX 第2章 2.3）。

Property は「**任意の〈前提〉について〈性質〉が成り立つ**」の形式で書く。Phase 4 で
property-based testing（PBT）のテストに変換され、`PROP-nnn` が ID として使われる。

| # | 対応要件 | 受入条件（例ベース） | Property（性質ベース） |
