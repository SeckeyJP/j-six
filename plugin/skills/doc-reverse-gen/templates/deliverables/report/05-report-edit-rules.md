## 記入ガイド（記入後は削除する）

- **この成果物が帳票5点の中で最も重要**。レイアウトと項目一覧は実物を見れば分かるが、
  **転記のしかたと計算規則**は読み取れない。制度上の計算規則がある場合は必ずここに書く。
- **禁止事項を書く**。「やってよいこと」だけ書くと、等価に見える誤った実装が後から入る。
  誤った方法の結果を具体値で示し、正しい値との差を明記する。
- **根拠の出典を付ける**。制度上の計算規則は、一次資料（官公庁の公開資料）の URL を書く。
- **書き落としやすい点**: 改ページ制御を「委ねている」こと。制御していないなら、
  していないと書く。書かないと「制御済み」と誤読される。
