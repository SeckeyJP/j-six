## 合意成熟度

本書の成果物は実装済み・テスト通過済みの状態から起こした **Phase 6 時点の版**である。
逆生成した9点（③ ⑪〜⑱）は内容が実装と一致しているが、サンプルのため顧客による確認は行っておらず、
完成レベルの条件のうち「双方が確認できた」は満たしていない。人手で書く①②④はドラフトであり、
仕掛レベルにとどまる。成果物ごとの到達基準は
[`templates/deliverables/README.md`](../../../../templates/deliverables/README.md) の「合意成熟度」を参照。

## 設計書への組立

顧客様式の設計書は [`docs/design-docs/`](../design-docs/) に組み立てた。プロジェクトの組立定義
（`docs/design-docs/assembly-*.md`）が無く、顧客と目次を合意していないため、Skill 同梱の
基本設計書・詳細設計書の組立例をそのまま使っている。**設計書は直接編集せず、本ディレクトリの
成果物（さらにその逆生成元）を直してから組み立て直す。**
