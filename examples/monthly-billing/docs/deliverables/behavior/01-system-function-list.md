## システム化しない業務を載せる理由

「やらないこと」を発注者と明示的に合意するため。IPA ガイドが挙げる齟齬の類型に
「開発者が何らかの理由により誤認・拡大解釈し、実現範囲に盛り込んでしまった」がある。
対象外を書かないと、この齟齬は防げない。

本システムでは G1 のスコープ検査が、タスクの許可ファイル範囲を機械的に検査することで
実装レベルの拡大解釈も止めている（`.jsix-checks.json` の `gates.g1.scope`）。
