# 工程成果物テンプレート（27点）

IPA「[機能要件の合意形成ガイド](https://www.ipa.go.jp/archive/files/000004517.pdf)」が想定する
**工程成果物27点**の空テンプレート。記入済み実例は
[`examples/monthly-billing/docs/deliverables/`](../../examples/monthly-billing/docs/deliverables/)
にある（同じディレクトリ構成・同じファイル名なので、並べて見比べられる）。

## この単位で作る理由

IPA 自身が、外部設計工程には業界標準の工程成果物が存在しないこと、および
**工程成果物と設計書は1対1ではない**ことを明記している。

> 外部設計工程には、現時点では業界として標準とされる「工程成果物」が存在しません。
> …設計書の作成単位や構成が、本ガイドで想定している「工程成果物」と一致しないことがあります。
> 例えば、画面編では、「工程成果物」として「画面レイアウト」、「画面入出力項目一覧」、
> 「画面アクション明細」などを想定していますが、実際のプロジェクトでは、これらを合わせて
> １つの「ユーザインタフェース設計書」として作成する場合があります。
> — 同ガイド 概要編 2.1

したがって「基本設計書」のような大きな単位ではなく**工程成果物の粒度**で作り、
顧客の様式に応じて束ねる。束ね方は `assembly/` に定義する（Step 5 で作成）。

## 由来の内訳

| 由来 | 件数 | 乖離リスク |
|---|---|---|
| コードから逆生成 | 16 | **原理的にゼロ** |
| 受入テストから逆生成 | 1 | **ゼロ**（通っているテストが根拠） |
| コード＋Spec の併用 | 3 | 一部残る |
| Spec / CLAUDE.md（人手） | 7 | 残る |

27点中17点が実物から自動で起こせる。**人手更新が必要なのは「なぜ作るか」「どう運用するか」を
記す7点に限られる**。これが J-SIX の3層ドキュメント戦略の主張そのものである。

## 使い方

1. 必要な領域のディレクトリを `docs/deliverables/` にコピーする
2. 各ファイルの冒頭（対象・版・日付・逆生成元）を埋める
3. `[TODO: ...]` を埋める
4. 末尾の「記入ガイド（記入後は削除する）」の節を削除する

### 作る順序

人手で書く成果物が、逆生成する成果物の前提になる。この順で作る。

```
Phase 1-2  要求 Spec / Design Spec / ADR
    ↓
  ① システム化業務一覧・② 業務フロー・④ 共通ルール（人手。合意の対象）
    ↓
Phase 3-4  hold-out 受入テスト → 実装
    ↓
  ③ システム化業務説明（受入テストから逆生成）
    ↓
Phase 6  ⑤〜㉗（コードから逆生成）
```

### 27点すべてを作る必要はない

対象システムが持たない領域は作らない。API のみのシステムなら画面6点・帳票5点・バッチ4点は
該当しない（[`examples/approval-workflow/`](../../examples/approval-workflow/) がその例）。
**作らない領域は「該当なし」と記録する。**空欄のまま放置すると、抜けなのか対象外なのかが
区別できなくなる。

### 顧客の様式に合わせる

工程成果物と設計書は1対1ではない。顧客が「ユーザインタフェース設計書」のような
大きな単位を求める場合は、該当する工程成果物（画面③④⑤など）を束ねて提出する。
束ね方の定義は `assembly/`（Step 5 で作成）に置く。

## 合意成熟度

IPA ガイドは合意形成を3段階に分けている（同ガイド 3.1.1）。

| レベル | 定義 | J-SIX での対応 |
|---|---|---|
| 仕掛レベル | 発注者が「言い切った」、開発者が「聞き切った」 | Phase 1 要求 Spec のドラフト |
| 充実レベル | 図表に書いてレビューを繰り返し、合意内容が充実する | Phase 2 Design Spec ＋ 動くプロトタイプ |
| 完成レベル | 合意内容が管理され、双方が確認できた | Phase 2 品質ゲート（設計レビュー）通過 |

逆生成する成果物（17点）は、**実装済み・テスト通過済み**の状態から起こすため、
作成した時点で完成レベルにある。

## 出典について

IPA「機能要件の合意形成ガイド ver.1.0」（2010年3月31日）に基づく。同ガイドは
発注者ビューガイドライン ver.1.0 の改訂版であり、現在は IPA のアーカイブに置かれている。
**項目名と構造を参照した独自のテンプレート**であり、ガイドの様式を引き写したものではない。
